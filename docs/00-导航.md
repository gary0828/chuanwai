## 1. 四条铁律（防止文档腐化）

1. **单一事实源**：同一件事只在一处定义，其它地方放链接。复制 = 双份 = 必然过期。
2. **会变的与不变的分开**：计划、进度可以改；**ADR 只追加、不修改**。
3. **不知道写哪就别新建**：先记进 `memory/logs/YYYY-MM-DD.md`，下次整理时再定归属。
4. **改代码就要改文档**：接口 → `04-API/`；表结构 → `server/database.md`；部署 → `06-部署/`；约定与踩坑 → `03-开发指南/`；发版 → `CHANGELOG.md`。
