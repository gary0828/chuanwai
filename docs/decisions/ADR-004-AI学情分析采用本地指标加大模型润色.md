# ADR-004：AI 学情分析采用「本地指标 + 大模型润色」，禁止 text2sql

- **状态**：已接受
- **日期**：2026-09-12
- **决策人**：校长（业务方）
- **相关**：[[ADR-002-家校不做家长端与出网触达]]、[[ADR-005-课堂评价采用全班默认良好只标异常]]、[[ROADMAP]]

## 背景

业务方希望「AI 追查学生学习情况，结合日常表现和过往成绩生成学情分析」。需要确定：AI 怎么算、数据怎么出网、产出给谁看。

关键约束：
- 部署环境**内网可出公网**，可调 DeepSeek 官方 API
- **所有数据本地保存**（含未来扩展的知识库、题库）
- 数据含未成年人个人信息，受《个人信息保护法》约束

## 决策

### 1. 采用混合方案，不是"把数据扔给大模型"

- **结构化指标全部本地 SQL 计算**：出勤率、成绩趋势与波动、知识点掌握度、离群检测
- **只把指标结果送给大模型生成自然语言文字**
- **所有出现在报告里的数字，必须来自本地计算结果，不是大模型生成的**

理由：大模型做算术和统计会幻觉。让模型算"出勤率 87.3%"是拿校长决策开玩笑；让模型把一个确定的 87.3% 解释成"出勤良好但近期有下滑趋势"，才是它擅长的。

### 2. 严格字段白名单脱敏

**允许出网**：学号（内部 ID）、年级、结构化指标数值、知识点名称
**禁止出网**：学生姓名、家长姓名、家长电话、任何金额

脱敏逻辑硬编码在 LLM provider 层，不允许业务代码绕过。

### 3. 未配置 API Key 时自动降级

`base_url` / `model` / `api_key` 全部环境变量可配。未配置或调用失败 → 自动使用规则引擎模板版报告，页面明确标识「规则生成（未启用 AI）」。**保证断网也能用。**

### 4. 生成记录落库可审计

记录生成人、时间、模型名、输入指标快照，结果可回看、可打印、可复现。

### 5. 「校长自然语言问数」降级，禁止 text2sql

原需求是自然语言问数，但**通用 text2sql 会让模型写错 SQL 或理解错指标口径**，产出一个看起来专业、实际错误的数字——校长拿它做决策会出事。

因此本期**降级为「预置指标语义问答」**：
- 只允许命中 `/api/analytics/metrics` 已定义的 12 个指标
- 语义匹配 + 槽位填充，**不允许生成任意 SQL**
- 命中不了就明确回答"这个问题我答不了"并列出可问清单

## 影响

- 新增 LLM provider 抽象层（Phase 4）
- 现有 `/api/analytics` 端点的 12 个指标定义成为问答能力的边界
- 大模型调用成本 = token 费用，学员 500 人 × 每学期若干次，成本极低

## 复审条件

- 若未来本地部署开源模型，脱敏要求可放宽，但白名单机制保留
- 若 text2sql 有可靠的事实校验层（如查询后自动校验 + 指标字典强约束），可重新评估
