## 3. 维护纪律（防止重新变胖）

1. 新知识点一律写进本目录，**不要**往 `memory/MEMORY.md` 或 `README.md` 里堆细节。
2. 日志只记结论（做了什么 / 决策 / 为什么 / 踩坑），过程细节不进日志。
3. 发现本目录里某条**过时了**（如代码已改），**立刻改**，别留过期信息。
4. 单文件超 15 KB 就拆分，或降级为索引。
