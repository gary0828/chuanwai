# 前端两端差异（教务端 vs AI 工作台）

> 目的：**新增页面前必读**。这两端**都用了 Element Plus**，但外壳与变量完全不同，
> 看错会写出"与全站割裂"的页面（2026-09-21 已踩过一次，整页像"没样式的白板"）。

---

## 1. 一句话对照

| | 教务端 | AI 工作台 |
|---|---|---|
| 路径 | `src/` | `ai-workbench/src/` |
| 构建 | 根目录 `vite build` → `dist/static/` | `ai-workbench/`（复用根 node_modules，无独立 package.json）→ `assets/` |
| 组件库 | ✅ Element Plus **全量** | ✅ Element Plus **全量**（`main.ts` 里 `app.use(ElementPlus)` + zh-cn） |
| pure-admin 壳 | ✅ **有** | ❌ **没有** |
| 排版靠什么 | pure-admin 骨架类 + 全局覆盖 | `styles.css` 的 `.card/.tag/.empty/.tip` + **各页 scoped CSS** |

★ **最容易错的认知**：以为工作台是"轻量无组件库"。**不是** —— `el-button/el-select/el-input/
el-radio-group/el-radio-button/el-tabs/el-checkbox/el-date-picker` 在工作台到处都在用。

---

## 2. 教务端（`src/`）

- 骨架：**`.app-page` + `AppPageHeader` + `.page-card`（可 `--flush`）+ `.page-toolbar`**
- 空状态：`AppEmpty`
- 数字列：`.num` 右对齐
- 颜色/间距/圆角/阴影走 **`src/style/tokens.scss`（唯一权威源）**，页面**禁硬编码色值**
- Element 重定义在 `element-plus-override.scss`，**必须晚于 `element-plus/dist/index.css` 引入**
  （靠加载顺序取胜，**别加 `!important`**）
- thin 版**不含 `ReUpload` / `ReCropper`** → 上传用**全局注册的 `el-upload`** + `:http-request`
- 视觉方向见 `.impeccable.md`（中度重塑 / 专业信赖 / 台式+平板优先；品牌主色 `#1F5C99`）

## 3. AI 工作台（`ai-workbench/src/`）

- 外壳用全局类（定义在 `styles.css`）：`.card` `.card-head` `.card-title` `.card-sub`
  `.card-body` `.sec-title` `.tag`（+ `tag-blue/green/amber/red/gray/cyan`）`.empty` `.tip`
- **`el-*` 照用**，但**排版要抄工作台自己的页面**，别照搬教务端的骨架类
- 参照页：**`views/Settings.vue`**（表单/分区/按钮的标准写法）、`views/Teaching.vue`（采集表单）
- 表单行：`.form-row`（`display:grid; grid-template-columns: 180px 1fr; gap:12px; align-items:start`）
- 列表：**`.rec-head` / `.rec-row` 的 grid**，**工作台不用 `el-table`**
- 图标：`~icons/ep/*`（如 `~icons/ep/plus`、`~icons/ep/info-filled`）
- 原生 `<button class="ghost-btn/mini-btn">` 是**既有惯例**（次要操作可用），但
  **`<input>/<select>/<textarea>` 一律不要原生** —— 用 `el-input` / `el-select` / `el-date-picker`

### ★★ 工作台 CSS 变量：是 `--c-*`，不是 `--brand` / `--line`

实际存在（`ai-workbench/src/styles.css`）：

```
--c-bg            --c-surface         --c-border          --c-border-strong
--c-text          --c-text-2          --c-text-3
--c-primary       --c-primary-dark    --c-primary-soft    --c-primary-line
--c-danger        --c-danger-soft     --c-warn            --c-warn-soft
--c-success       --c-success-soft    --c-info            --c-info-soft
```

★ **写成 `--brand` / `--line` / `--danger` 这类不存在的变量不会报错，只会静默失效。**
**写 scoped CSS 前先 grep 一遍 `styles.css` 确认变量存在。**（2026-09-21 踩过：自定义样式全失效）

---

## 4. 反面教材（真事）

`ai-workbench/src/views/Todos.vue` 初版：

1. 用了**原生 `<input>/<select>`** —— 全工作台只有它这么干，其它页一律 `el-input/el-select`
2. scoped CSS 写了 `var(--brand)` / `var(--line)` / `var(--danger)` —— **这些变量不存在**

两个错叠加 → 整页像"没样式的白板"。修法：照抄 `Settings.vue` 重写。
