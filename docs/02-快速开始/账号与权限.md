# 账号与权限

本系统是**纯员工端**系统：只有员工账号能登录，学员与家长无账号。

---

## 1. 默认账号

初始密码规则：**用户名 + 123456**。

| 账号 | 密码 | 角色 | 权限 |
| --- | --- | --- | --- |
| `admin` | `admin123456` | 管理员 | 全部功能（含员工账号、班级 / 课程管理、经营报表） |
| `teacher` | `teacher123456` | 教师 | 班级 / 学员管理、考勤登记与统计、请假管理、通知记录（**仅本班**） |

> ⚠️ 默认口令是公开信息，**首次登录后必须修改**。

账号由管理员在系统内创建，**不开放注册**。管理员不能删除自己，系统至少保留一个管理员。

---

## 2. 角色权限矩阵

| 功能 | admin | teacher |
| --- | --- | --- |
| 员工账号（创建 / 改角色 / 重置密码 / 删除） | ✅ | ❌ |
| 班级管理（增删改、指定班主任绑定） | ✅ | ✅ 仅本班（新建时自动绑定自己） |
| 学员管理（增删改、导入导出、家长信息） | ✅ | ✅ 仅本班 |
| 课程管理（增删改） | ✅ | ❌ |
| 招生线索（登记 / 跟进 / 流转 / 转化） | ✅ 全部 | ✅ 仅自己创建 |
| 教学结果（考试 / 成绩 / 成绩单 / 学习报告 / 成长档案） | ✅ 全部 | ✅ 仅本班考试与学员 |
| 课消统计 | ✅ 可见金额 | ✅ 仅本班，**金额不可见** |
| 家校通知（查看 / 标记已读） | ✅ 全部 | ✅ 仅本班学员 |
| 经营报表（招生 / 营收 / 续班 / 在读） | ✅ | ❌ |
| 考勤登记 / 记录 / 统计 / 趋势 / 预警 / 请假审批 / 首页看板 | ✅ 全部 | ✅ 仅本班数据 |
| 财务管理（报班 / 缴费 / 退费 / 统计） | ✅ | ❌（接口一律 403） |
| 系统管理（参数 / 公告 / 备份 / 审计日志） | ✅ | ❌ |

---

## 3. 四层权限如何同时生效

| 层 | 机制 |
| --- | --- |
| 菜单层 | 后端按角色下发动态路由（`/api/auth/async-routes`），无权限菜单根本不下发 |
| 接口层 | `requireRole("admin")` 等中间件，越权直接 403 |
| 数据层 | `server/src/utils/scope.js` 按 `classes.head_teacher_id` 过滤，教师只能取到本班数据 |
| 字段 / 导出层 | 金额类字段对教师脱敏；导出文件不含费用列 |

改动「谁能看到什么」之前，先读 [权限模型](../03-开发指南/权限模型.md)。

---

## 4. 权限收紧后的既有结论

- 财务（`orders` / `payments` / `refunds` / 统计）与招生线索的全部接口均为 `requireRole("admin")`，教师调用一律 403。
- 由于教师已完全不可达，`finance.js` 的 `financeScope` 与 `leads.js` 的 `leadScope` 已移除（原为恒空操作，只会给 SQL 拼接引入噪声）。
- 完整梳理见 `../archive/业务流程与权限梳理报告-2026-09-12.md`。
