## 一、项目定位

培训机构**员工端 CRM**（admin / teacher 两种角色；学生与家长**无账号、不登录**）。
单校区自用，规模：学员 200–500 / 员工 5–15。已部署生产（Docker Compose）。

| 层 | 技术 |
| --- | --- |
| 前端 | Vue 3.5 + TS + Vite 7 + Element Plus 2 + Pinia + Tailwind 4 + ECharts 6（基于 pure-admin-thin） |
| 后端 | Express 4 + Node 内置 `node:sqlite`（零原生依赖）+ JWT 双 Token + bcryptjs |
| 部署 | Docker Compose（nginx :8080 + node :3000 + SQLite 数据卷） |

默认账号：`admin/admin123456`、`teacher/teacher123456`（**上线后须改**）。

## 四、权限现状（2026-09-12 收紧后）

| 角色 | 可见范围 |
| --- | --- |
| `admin` | 全部 |
| `teacher` | **仅授课相关**：班级 / 学生 / 考勤 / 请假 / 补课 / 调课申请 / 课表 / 成绩 / 通知 / 学习报告（**金额脱敏**） |

- 财务（订单·缴费·退费·统计）与招生线索：**全部接口 `requireRole("admin")`，教师调用一律 403**。
- 四层同时生效：菜单不下发 / 接口 403 / 字段级脱敏 / 导出不含费用。
- 因教师已完全不可达，`finance.js` 的 `financeScope`、`leads.js` 的 `leadScope` 及其归属校验已于 2026-09-14 移除（原为恒空操作/恒 true，只会给 SQL 拼接引入噪声）。
- 详见 `docs/业务流程与权限梳理报告-2026-09-12.md`。

## 五、关键约定（改代码前必知）

1. **数据库变更**必须新增迁移脚本 `server/src/migrations/0NN-*.js`（版本连续，跳过会终止启动），并同步 `server/database.md`。当前 **v15**。
2. **API 变更**必须同步 `docs/api.md`（权威）与 `docs/openapi.yaml`。
3. **前端规范**遵循 pure-admin 官方：接口集中在 `src/api/`、views 内禁用 `$route`/`$router`/`localStorage`/axios；图标用 `~icons/ep/xxx`。
   3.1. **前端视觉**遵循 `docs/前端视觉规范-2026-09-18.md`：颜色/间距/圆角/阴影/动效一律走 `src/style/tokens.scss`（页面禁硬编码色值）；页面骨架 = `.app-page` + `AppPageHeader` + `.page-card(--flush)` + `.page-toolbar`；空状态用 `AppEmpty`。
4. **业务口径**：考勤只有 正常/迟到/早退 扣课时，**缺勤不扣**；销假回补仅针对这三类；退费审批通过 → 订单置「退班」，退班订单不参与扣减/回补。
5. **生产库**不得直接写（Docker bind mount 缓存会导致容器读到陈旧视图，改完须 `docker restart attendance-server`）。

## 六、常用命令

```bash
# 后端（开发，端口 3000；缺 JWT_SECRET 会拒绝启动）
cd server && JWT_SECRET=<值> node src/index.js
# 前端 dev（8848）
node ./node_modules/vite/bin/vite.js --port 8848

# 回归（注意：Node 18+ 的 fetch 优先解析 ::1，用 127.0.0.1 更稳）
BASE=http://127.0.0.1:3000 node server/scripts/e2e-lifecycle.mjs          # 80 项断言
BASE=http://127.0.0.1:3000 node server/scripts/analytics-smoke.mjs        # 22 项
BASE=http://127.0.0.1:3000 node _verify_test/probe-business-chain.mjs     # 业务链闭环 49 项
bash server/scripts/docker-verify.sh                                      # 部署验证 9 项
# 浏览器（接口登录+注入 token，不依赖登录页验证码）
"C:/Program Files/Python314/python.exe" server/scripts/ui-p0-verify.py http://localhost:8080 http://localhost:3000   # 31 项
# ★ 全页面冷启动巡检（改路由/菜单后必跑；28 个路由逐个独立 context 直达 + F5）
"C:/Program Files/Python314/python.exe" _verify_test/verify-all-pages.py http://localhost:8080 http://127.0.0.1:3000   # 28 项

# 部署（注意中文目录导致 compose --build 失败，须分两步）
docker build -t attendance-system-server -f server/Dockerfile .
docker build -t attendance-system-web -f Dockerfile .
docker compose up -d --no-build
```
