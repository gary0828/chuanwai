## ★★ 环境坑（按"会再次踩"排序）

1. **Bash 工具必须先 export PATH**：
   `export PATH="/c/Users/rui08/.workbuddy/binaries/PortableGit/versions/1.2.0/usr/bin:/c/Users/rui08/.workbuddy/binaries/PortableGit/versions/1.2.0/mingw64/bin:$PATH"`
   否则 `ls/dirname` 不可用；**docker 命令同样需要**。`cd` 必须与 `&&` 连用。

2. **Playwright 用系统 Python**：`C:/Program Files/Python314/python.exe`
   （**只有它有 requests + playwright**）。Node 用 `22.22.2-3`。

3. Node 18+ 的 `fetch` 优先解析 `::1` → 测试**必须**用 `http://127.0.0.1:3000`。

4. ★★ **`grep -r` + 通配符在本环境会「静默返回空」**
   （2026-09-21 被它坑掉一次结论：据此错误断言"工作台不用 Element Plus"）。
   → **扫代码一律用 Grep 工具（ripgrep）**。**"扫不到"要先怀疑命令，再下结论。**

5. ★ **批量删文件必须两步法**：`git rm --cached` 改索引 → 再单独 `rm -f`。
   ❌ `git rm --pathspec-from-file=` 在 Git Bash + Windows 下会 **SIGTERM 中断**：目标被删，
   **同目录下要保留的文件也连带消失**。
   ✅ 恢复：`git cat-file -e HEAD:<path>` → `git checkout HEAD -- <文件列表>`，**零丢失**。
   大通配符和长 `for` 循环同样易 SIGTERM → **显式文件名、分批 6–10 个**；
   `rm -rf <目录>` 也易中断 → `rm -f` 内部文件 + `rmdir` 逐级删。

6. ★ **本项目是 hash 路由** → 直连写 `http://host/#/welcome`；
   **写 `/welcome` 会被 nginx 当文件找而 404**。

7. **Vite dev server 在本沙箱卡死** → 用 `_verify_test/serve-dist.mjs`
   （但**它没有 nginx 层**，nginx 类问题测不出来）。

8. **登录限速内存计数会误伤多轮测试** → 重启后端清零，断言接受 400/429。

9. `vite-plugin-remove-console` v2.2.0 会删掉 `X && console.log(Y)` 里的 `X &&`
   造成语法错误 → 重下 `iconfont.js` 会带回该写法。

10. **真实库是 `server/data/attendance.db`**（**不是 `app.db`**，那是 0 字节残留）；
    `updated_at` 存 **UTC**（本地 −8h）。后端 Dockerfile **不能**加 `USER node`。

11. 本机 `pnpm` 不可用（corepack 损坏）→ 用 `npx --yes pnpm@10.15.1`；
    构建调 `node ./node_modules/vite/bin/vite.js build`。**无 `gh` CLI**。

## 仓库与推送

- **主通道 = gitee**：`git -c http.proxy= -c https.proxy= push gitee main`（**必须清代理**）。
  ★ **`git ls-remote` 同样要带 `-c http.proxy=`**。
- **备通道 = github**：`github.com` 不通（白名单代理 `127.0.0.1:11711` 一律 502），
  但 **`api.github.com` 可达** → `_verify_test/push-via-api.py`。
  - **三坑（脚本已内置校验，勿删）**：
    ① 用 `git show HEAD:<path>` 取**入库版本**（`core.autocrlf=true`）；
    ② 必须 `--name-status -z`，否则中文路径转义 → 取到**空 blob = 删掉远程文件**；
    ③ API commit SHA 与本地不同，追平需**时区 `+0800` + message 末尾无换行**，
       手工喂字节（**不能用 `commit-tree`**，它补换行）。
- **推送前安全三步**：
  ① `git diff --cached --name-only | grep -iE "\.env$|server/data/|\.db$"` **必为空**；
  ② 扫手机号/身份证；
  ③ 推后比 `git rev-parse HEAD` 与 `ls-remote` 的 **SHA**。
