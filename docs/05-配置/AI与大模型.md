# AI 与大模型

AI 教学工作台是**独立部署**的教学辅助站点（统一入口 `/ai`），从教务系统顶栏「AI 助手」按钮**免登进入**（后端签发 60 秒一次性票据）。

---

## 1. 不配大模型也能用

**未配置大模型 Key** 时，九个场景（课程设计 / 备课方案 / 授课流程 / 作业设计 / 批改反馈 / 学情诊断 / 家长反馈 / 学情报告…）**全部由本地规则引擎生成**，页面标注「规则引擎生成」。

**所有数字都由本地指标引擎算出，不依赖模型**（ADR-004：禁止 text2sql）。

---

## 2. 配置大模型（可选，在页面上配置）

管理员登录教务系统 → 访问 **AI 配置中心** `http://<地址>/#/ai-admin`（**不在任何菜单里**，只能输地址进；教师访问 403，页面只显示 Key 掩码）→ 填入 Key / 模型 / 额度 → **保存即生效，不用重建容器**。

> ★ 2026-09-23 起**唯一入口就是这个页面**：大模型参数存数据库 `settings` 表，**不再经 `.env` / compose 注入**。此前「往 `.env` 写 `LLM_API_KEY` 再重建容器」的做法已废弃（`config.js` 仅保留环境变量作末位兜底）。
> 生效后：工作台 → **底座设置** → 选「服务端模型」→ 保存，右下角显示当前模型名。

---

## 3. 可调项（均在「AI 配置中心」页面）

全部可选，默认值已是最优，详见 [环境变量](环境变量.md) §3。

| 配置项 | 默认 | 什么时候要动 |
| --- | --- | --- |
| 模型 `llmModel` | `deepseek-flash` | 换更强的 `deepseek-v4-pro`（慢约 3.6 倍、更贵） |
| 思维链 `llmReasoningEffort` | `none` | 想让模型做多步推理才改 `medium` / `high`，**必须同时调大额度** |
| 输出额度 `llmMaxTokens` | `8192` | 开启推理后需上调 |
| 超时 `llmTimeoutMs` | `60000` | 网络较慢时上调 |
| `AI_WORKBENCH_URL`（部署期，非页面） | `http://localhost` | 仅当工作台部署在**另一台机器**时显式配置 |

---

## 4. 安全边界

- **Key 只存在于服务端**（数据库 `settings` 表），永不下发浏览器；工作台经 `/api/ai/generate` 走后端代理。
- 出网前经服务端二次脱敏（姓名 / 电话 / 金额 / 含金额特征的文本一律剔除），学员以**内部编号**送出。
- 模型调用失败自动回退规则引擎并标注原因，**不阻塞教学流程**。
- 实测单次生成约 **7 秒 / ¥0.011**；每天 30 份报告约 ¥10 / 月。

---

## 5. Dify 的定位

Dify 是**加工厂（只读检索），不是仓库**（ADR-008）：

| 数据类别 | 归属 |
| --- | --- |
| 具体学员 / 班级的业务数据与 AI 产出 | **本系统**（索引入库 + 文件落盘 `server/data/assets/`） |
| 通用参考资料（教学法 / 话术 / SOP / 学科知识） | Dify 知识库（只读） |

- 取数只能走 `/api/agent/*`，脱敏后送模型；密钥服务端代持，前端零密钥。
- 产出层分期：xlsx（已有）→ PDF → PPT → 视频（暂缓）。
- 上手步骤 → [Dify 上手指南](../08-参考/Dify上手指南.md)。
