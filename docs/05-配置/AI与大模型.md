# AI 与大模型

AI 教学工作台是**独立部署**的教学辅助站点（统一入口 `/ai`），从教务系统顶栏「AI 助手」按钮**免登进入**（后端签发 60 秒一次性票据）。

---

## 1. 不配大模型也能用

`LLM_API_KEY` 留空时，九个场景（课程设计 / 备课方案 / 授课流程 / 作业设计 / 批改反馈 / 学情诊断 / 家长反馈 / 学情报告…）**全部由本地规则引擎生成**，页面标注「规则引擎生成」。

**所有数字都由本地指标引擎算出，不依赖模型**（ADR-004：禁止 text2sql）。

---

## 2. 配置大模型（可选）

在**项目根目录 `.env`**（compose 自动读取，文件已 gitignore）加一行：

```bash
LLM_API_KEY=sk-xxxxxxxxxxxxxxxx
```

重建后端容器让环境变量生效：

```bash
docker build -t attendance-system-server -f server/Dockerfile .
docker compose up -d --no-build --force-recreate server
```

生效后：工作台 → **底座设置** → 选「服务端模型」→ 保存，右下角显示当前模型名。

> 更省事：管理员访问 `http://localhost:8080/#/ai-admin`（**不在任何菜单里**，只能输地址进）可直接在页面上改 Key / 模型 / 额度 / 工作台地址，**保存即生效，不用重建容器**。教师访问会被 403，页面只显示 Key 掩码。

---

## 3. 可调项

全部可选，默认值已是最优，详见 [环境变量](环境变量.md) §3。

| 变量 | 默认 | 什么时候要动 |
| --- | --- | --- |
| `LLM_MODEL` | `deepseek-flash` | 换更强的 `deepseek-v4-pro`（慢约 3.6 倍、更贵） |
| `LLM_REASONING_EFFORT` | `none` | 想让模型做多步推理才改 `medium` / `high`，**必须同时调大额度** |
| `LLM_MAX_TOKENS` | `8192` | 开启推理后需上调 |
| `LLM_TIMEOUT_MS` | `60000` | 网络较慢时上调 |
| `AI_WORKBENCH_URL` | `http://localhost` | 仅当工作台部署在**另一台机器**时显式配置 |

---

## 4. 安全边界

- **Key 只存在于后端容器**，永不下发浏览器；工作台经 `/api/ai/generate` 走后端代理。
- 出网前经服务端二次脱敏（姓名 / 电话 / 金额 / 含金额特征的文本一律剔除），学员以**内部编号**送出。
- 模型调用失败自动回退规则引擎并标注原因，**不阻塞教学流程**。
- 实测单次生成约 **7 秒 / ¥0.011**；每天 30 份报告约 ¥10 / 月。

---

## 5. Dify 的定位

Dify 是**加工厂（只读检索），不是仓库**（ADR-008）：

| 数据类别 | 归属 |
| --- | --- |
| 具体学员 / 班级的业务数据与 AI 产出 | **本系统**（索引入库 + 文件落盘 `server/data/assets/`） |
| 通用参考资料（教学法 / 话术 / SOP / 学科知识） | Dify 知识库（只读） |

- 取数只能走 `/api/agent/*`，脱敏后送模型；密钥服务端代持，前端零密钥。
- 产出层分期：xlsx（已有）→ PDF → PPT → 视频（暂缓）。
- 上手步骤 → [Dify 上手指南](../08-参考/Dify上手指南.md)。
