# 环境变量

模板见 `server/.env.example`（后端）与根目录 `.env.example`（前端）。**真实密钥一律通过环境变量 / Compose / 密钥管理注入，绝不写进仓库。**

---

## 1. 加载方式

后端不依赖 dotenv，使用 Node 原生 `--env-file-if-exists=.env`（见 `server/package.json` 的 `start` / `dev` 脚本）：

- 本地开发：`cp server/.env.example server/.env` 后自动生效
- Docker：由 `docker-compose.yml` 的 `environment` 注入（**优先级更高**）
- 直接运行：先 `export JWT_SECRET=...` 再 `node src/index.js`

前端自定义变量**必须以 `VITE_` 开头**，改完必须重启 dev server。

---

## 2. 后端变量

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `JWT_SECRET` | **是** | 无 | 双 Token（access 7d / refresh 30d）签名密钥。**缺失时拒绝启动**，不会回退默认值。建议 `openssl rand -hex 32` 生成，并纳入轮换计划 |
| `PORT` | 否 | `3000` | 后端监听端口 |
| `CORS_ORIGINS` | 否 | 本机 8080 / 8848 | 逗号分隔白名单。生产同源（nginx 反代 `/api`）不经过 CORS，通常无需设置 |
| `LOGIN_RATE_LIMIT_MAX` | 否 | `10` | 同 IP 15 分钟窗口内的登录**失败**次数上限；成功登录不计数 |

> ⚠️ 轮换 `JWT_SECRET` 会让所有已签发 Token 立即失效，需通知全体员工重新登录，建议在非教学时段执行。

## 3. AI 相关

> ✅ 2026-09-23 起：**大模型参数不再经 `.env` / Compose 注入**，改为在系统内
> **「AI 配置中心」页面**（`/#/ai-admin`）配置 —— 存数据库 `settings` 表，保存即生效，
> Key 只留在服务端、永不下发前端。仅 `AI_WORKBENCH_URL` / `AI_WORKBENCH_BASE_PATH`
> 仍属**部署期变量**（由 Compose 注入）。

**页面上可配（存 DB，不写 `.env`）**：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 大模型 API Key（`llmApiKey`） | 空 | DeepSeek（或任意 OpenAI 兼容端点）Key。**留空时工作台仍完全可用**，全部场景降级为规则引擎 |
| Base URL（`llmBaseUrl`） | `https://api.deepseek.com` | 换国产模型 / 本地 vLLM / Ollama 只需改这一项与模型名 |
| 模型（`llmModel`） | `deepseek-flash` | 旧别名 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 停用 |
| 思维链强度（`llmReasoningEffort`） | `none` | **保持 `none`**。推理型模型的思维链会先吃满输出额度导致正文为空；要推理必须同时调大输出额度 |
| 输出额度（`llmMaxTokens`） | `8192` | 关闭推理时一份备课方案约 1900 输出 token，余量充足 |
| 超时（`llmTimeoutMs`） | `60000` | 网络较慢时上调 |

**部署期变量（Compose 注入）**：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `AI_WORKBENCH_URL` | `http://localhost` | 同源部署保持默认即可，后端会替换为「访问者当前访问的地址」，IP / 域名 / 端口 / HTTPS 全部自适应。仅当工作台在**另一台机器**时才显式配置 |
| `AI_WORKBENCH_BASE_PATH` | `/ai` | 同源部署且工作台挂在子路径时配置 |

配置步骤与免登跳转、AI 配置中心 → [AI 与大模型](AI与大模型.md)。

## 4. 前端变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `VITE_PORT` | `8848` | 开发端口 |
| `VITE_PUBLIC_PATH` | `/` | 部署公共路径 |
| `VITE_ROUTER_HISTORY` | `hash` | 路由模式（`hash` / `h5`；可带 base 参数 `hash,base`） |
| `VITE_CDN` | `false` | CDN 开关 |
| `VITE_COMPRESSION` | `none` | 构建压缩（`none` / `gzip` / `brotli`） |

> ★ 构建期 env（`.env.development` / `.env.production` / `.env.staging`）只含 `VITE_*`、**不含任何密钥**，
> 自 2026-09-23 起**已纳入版本库**（`.gitignore` 只忽略 `.env` 与 `*.local`）。
> 刻意为之：`git clone` 部署时若缺 `VITE_ROUTER_HISTORY`，前端会在启动瞬间崩溃、整页白屏。

---

## 5. 安全底线

- ❌ 任何密钥不得出现在前端任何位置（localStorage、打包产物、URL 都不行）。
- 模型调用一律走服务端 `POST /api/ai/generate`，Key 只存在于后端容器。
- `.env`（根目录与 `server/`）已被 `.gitignore` 排除；构建期 `VITE_*` 的 `.env.development` / `.env.production` / `.env.staging` 不含密钥、已纳入版本库。提交前仍应扫一遍敏感数据（真实学员数据 / 密钥）。
