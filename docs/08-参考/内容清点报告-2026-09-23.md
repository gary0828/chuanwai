## 3. 明细

### A 类：写死 / 演示内容 —— 未发现

- 全项目仅 2 个页面用 ECharts（`welcome`、`attendance/statistics`），二者 `data` 均由接口结果 `map` 得出；对 `src/views` 全量 grep `data:\s*\[` **零匹配**。
- 所有列表 ref 均为**空初始化 + 接口填充**（`const dataList = ref<any[]>([])`），无 `ref([{...}])` 业务数据。
- grep `= [{` 命中 8 处，**全部是枚举/校验常量**（考勤状态、订单状态、考试类型、角色、退费状态、支付方式、两处上传 MIME 白名单）→ 属白名单范围。
- 无 mock 残留：`src/**/{data,mock,mockData}.{ts,js}` 无结果，`from "*/mock"` 无匹配。

### B 类：永远为空 / 名不副实的字段

**唯一真问题：B-1 铃铛条目 `avatar` 是死字段。**
`NoticeItem.vue:54-59` 用 `v-if="noticeItem.avatar"` 渲染头像，但数据组装方 `lay-notice/index.vue` 的
`toNoticeItem`（64-72）/`toTodoItem`（74-93）**从未赋值 `avatar`**，`types.ts:9` 也只是可选字段。
这是 09-21 删除演示数据（含 3 个 GitHub 头像外链）后留下的空壳；因被 `v-if` 拦住，**只表现为"永远没有头像"，不会破图**。
→ 建议连同 `types.ts:9` 一并清理，**防止将来有人误把外链填回去**。

**运行时探针捞出的 16 个"恒为空字段"——溯源后全部不算缺陷（如实说明）：**

| 字段 | 出现于 | 溯源结论 |
|---|---|---|
| `remark`（备注） | exams · leads · finance/orders · finance/payments · finance/refunds · attendance/records（6 个模块） | **有录入入口、界面有列**（如 `exams/index.vue:492` 备注表单项、`payments/index.vue:432` 创建弹窗、`leads/index.vue:607` 编辑弹窗）→ 只是**演示数据没填**，不是死字段 |
| `students.email` | 学员列表 | 有入口（表单 `index.vue:448` + Excel 导入 `123`）→ 演示数据没填 |
| `users.phone` | 员工列表 | 种子账号未填；**2026-09-23 起个人中心可自助填** |
| `leads.course_id / course_name / student_no / converted_name` | 招生线索 | 演示线索**均未转化**故为空；后端确有 JOIN（`leads.js:55-56、71`） |
| `todos.creator_id / due_date / completed_at / creator_name` | 待办 | 演示待办未指派/未设截止/未完成 |

> ⚠ **诚实边界**：本地库是**演示/种子数据**，某字段为空 ≠ 生产恒空。以上结论基于"是否有录入入口"这一代码事实，**不是**基于数据是否为空。
