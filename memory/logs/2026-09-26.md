- **根因**: `before-upload` 的参数是 **UploadRawFile**（`extends File`，**无 `raw` 字段**；
  `raw` 只在 change 事件的 `UploadFile` 上），代码却读 `file.raw` → undefined →
  `readAsArrayBuffer(undefined)` **同步抛错**；而 try/catch 只包了 `reader.onload` 的**内部** →
  无人接管 → 无请求无提示。**参数标成了 `any` 才让类型检查没拦住**。
- **修复**: 传 `file` 本身 + 补三条反馈路径（reading 失败 / 业务 success:false / catch）+ loading + 防重复提交
- **连带修复 4 个同源缺陷**: ①模板「来源渠道/报名日期」未映射 → 静默丢数据（P1）
  ②无 loading（P2）③`.then` 无 catch、success:false 无 else（P2）④模板示例班级名不存在（P2）
- **验证**: 修复后 **PASS 29 / FAIL 0**；含错误班级→明确提示指明行号；重复导入→逐行列出「学号已存在」
