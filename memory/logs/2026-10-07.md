### ★ 顺带修掉 openapi.yaml 两处**历史遗留**缺陷

1. `/api/period-times/{period}` 这个 path **错放在 `components:` 之下**，吸收了文件末尾的 schema
   —— 本次追加的 15 个 QBank schema **全被吞进去**（`components` 下多出一个 path 键）。
   HEAD 里就有（L2905 > components L2299），一直没人发现。
2. 一句 `（view=class/teacher/all…）` **缩进为 0**，导致整个 YAML 解析失败。
   来源：`_verify_test/_tmp/patch-openapi-v23.mjs`（v23 时期的补丁脚本遗留）。

★ **教训**：门禁 `check-openapi.mjs` 只验「YAML 能解析 + $ref 能解析」，
**验不出结构语义错误**（path 放错地方照样「通过」）。这两个都是靠**自查**发现的
（我用 `YAML.parse` 后逐一核对 `components` 下的键与 `schemas` 数量，才暴露出来）。
⇒ **值得考虑给门禁补一条**：`components` 下不应出现非 `securitySchemes/responses/parameters/schemas`
的键（那种键一定是 path 错位）。
