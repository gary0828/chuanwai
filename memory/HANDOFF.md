# HANDOFF · 上下文交接（按需）

> 用途：**长会话 / 上下文将满 / 要换人接手**时，把当前状态落盘，让新会话能无损接上。
> 规矩：交接成功后即可清空本文件（保留骨架）。**平时不要读它**（`route.mjs` 里不属于必读）。
> 参考业界做法：context 快满时先写 HANDOFF 再开新会话，比硬撑更省 token、更少出错。
