### 发现问题（同类根因，均严重）

- **[严重] P3-A**：`PUT /classes/:id` 请求体不带 `head_teacher_id` → **500 服务器内部错误**。根因：classes.js PUT 中 `headTeacherId` 为 `undefined`（`head_teacher_id !== undefined` 分支不成立），`COALESCE(?, head_teacher_id)` 将 undefined 传给 node:sqlite `run()`，无法绑定 → 500。已实测：传 `head_teacher_id: null` → 200 正常。**修复方案**：PUT 未传 head_teacher_id 时置 null（`head_teacher_id ?? null`），或对缺省字段做默认值处理。
- **[严重] P3-B**：`PUT /students/:id` 请求体缺省 gender/phone/email/status 任一 → **500**。根因：students.js PUT 直接 `run(student_no, name, gender, phone, email, ..., status, id)`，缺省字段为 undefined → node:sqlite 绑定失败。**修复方案**：缺省字段给默认值或先取原值（`body.gender ?? cur.gender`）。
- 两者为同一缺陷模式：**后端 PUT 对缺省字段未做默认/保留处理，直接传 undefined 导致 500**（node:sqlite 只能绑定 null/数字/字符串等，不能绑定 undefined）。建议统一修复并加回归断言。
