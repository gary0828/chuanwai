## 5. 数据可见性验证（跨模块出现位置）

**机制说明**：每新增/修改/删除一个核心实体，不仅要验证"该功能本身"是否实现，还要按下表**逐处查找该数据**，确认它在所有应出现的位置都能找到、且数据一致。这是兜住"功能实现了但数据没流到消费方"的联动缺陷（v1-v13 典型问题之一）。

**测试动作**：新增实体 → 打开该实体清单中的每一个出现位置 → 逐一确认能找到、数据与源头一致 → 记录缺失项。

| 核心实体 | 出现位置（应能找到它的所有地方） | 关键一致性 |
|---|---|---|
| 学生 | 学生管理列表/详情、班级成员、课表（按班）、考勤记录筛选、请假列表筛选、补课列表、考试名单/成绩、学习报告/成长档案、课消流水、订单/缴费/退费、家长绑定（家长端看孩子）、通知（缺勤/审批）、仪表盘、经营报表、审计日志 | 姓名/学号/班级/状态各处一致 |
| 课程 | 课程管理、班级（关联课程）、课表、考试、补课、经营报表（课程维度） | 名称/课时/价格一致 |
| 班级 | 班级管理、课表（按班）、考勤批量选择、学生列表（成员）、调课、补课、经营报表 | 学员数与实际一致 |
| 线索 | 线索管理列表、转化后→学生页、审计日志 | 转化后线索状态正确 |
| 请假单 | 请假管理列表、考勤记录（联动标记）、审批通知、请假统计 | 状态（待审批/通过/驳回）同步 |
| 调课单 | 调课管理、课表（变更后）、冲突检测、审计日志 | 新旧时间正确 |
| 补课单 | 补课管理、课消流水（核销）、学生考勤 | 核销后课时变化正确 |
| 订单/缴费 | 订单列表、学生财务、缴费记录、退费、经营报表（收入）、课消（剩余课时） | 金额/课时一致 |

| 课表 | 课表管理、考勤生成、调课冲突检测 | 时间/教师/教室无冲突 |
| 考试/成绩 | 考试列表、成绩录入/查看、学习报告、成长档案 | 分数同步 |
| 公告/通知 | 公告列表、家长/学生端可见 | 权限范围内可见 |

## 6. 角色权限矩阵

每个功能除管理员视角外，还要验证不同角色的**可见范围与操作权限**（CRM 多角色核心面）。

| 角色 | 可访问模块 | 关键权限边界 |
|---|---|---|
| 管理员 | 全部模块 | 审批/删除/退费/设置/备份/审计日志 全量 |
| 教师 | 自己班级相关的课表/考勤/请假/调课/补课/成绩 | 不能进入财务/用户/系统设置 |

| 学生 | 自己的课表/考勤/成绩 | 只能看自己 |

**测试动作**：每个阶段的功能，切换 2-4 种角色登录验证：能看到的列表范围、能点的操作按钮、越权访问返回 403。

## 8. 异常与回滚场景

补充到各功能的边界验证中：

- **删除受保护数据**（有订单学生/有课表班级/有成绩考试）→ 系统拦截、数据完好、错误提示明确
- **重复提交/双击** → 防重，不产生重复数据（请假单、订单、补课单）
- **非法输入**（超长/空/错误类型）→ 前端校验 + 后端兜底，不落脏数据
- **无权限访问** → 403 页面，不泄露接口数据
- **并发操作**（同学生同时请假+打卡、同时缴费+退费）→ 数据不冲突、不超扣课时

## 11. Playwright UI 自动化辅助

**用途**：我首跑时用 Playwright 脚本执行 UI 层操作 + 截图留证，适用于"按你描述跑流程"与"逐处验证出现位置"，你复测时可对照截图。

**脚本示例**（Python，参照 webapp-testing skill；选择器以实际页面 DOM 为准，运行前先 `page.wait_for_load_state("networkidle")`）：

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    # 前端地址（Docker 环境）
    page.goto("http://localhost:8080")
    page.wait_for_load_state("networkidle")
    # 登录（占位选择器，按实际页面调整）
    page.fill("input[placeholder='用户名']", "admin")
    page.fill("input[placeholder='密码']", "123456")
    page.click("button:has-text('登录')")
    page.wait_for_load_state("networkidle")
    # 进入学生管理，新增学生（占位流程）
    page.click("text=学生管理")
    page.click("button:has-text('新增')")
    page.fill("input[placeholder='姓名']", "e2e_test_张三")
    page.click("button:has-text('保存')")
    page.wait_for_load_state("networkidle")
    # 留证截图
    page.screenshot(path="evidence/student_create.png", full_page=True)
    browser.close()
```

**运行说明**：每段脚本先确认选择器（截图/控制台检查），再执行；截图统一存 `evidence/` 目录；脚本只用于辅助验证，**最终确认以你实际操作为准**。

## 12. 问题分级

| 级别 | 定义 | 处理 |
|---|---|---|
